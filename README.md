# BlueROV2 Heavy - Gazebo - ROS - Qualisys
This repository includes the code for testing guidance, navigation and control algorithms for a **BlueROV2 Heavy** vehicle. The code can be run in a simulated environment in Gazebo, or  can be deployed in a real-world setup using Qualisys motion capture system. In both cases, the system uses **ROS**.

- The folder 'eight-thruster' is for deployment in a simulated **ROS-Gazebo** framework.

- The folder 'real_world' is for deployment of the real vehicle using **ROS-Qualisys** (some files are shared with 'eight-thruster', but tuning is different).
